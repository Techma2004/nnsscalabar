# Database

The portal uses **PostgreSQL only** (local Postgres or Supabase).

- **Use:** `postgres/schema.sql` — complete, current schema. Run it once on a new database. Safe to run again.
- **Legacy (do not use):** everything in `legacy-mysql/` is from the old MySQL version, kept for history only.

Setup guides: `../INSTALL.md` (PC), `../SERVER.md` (own server), `../DEPLOY_VERCEL.md` (online).
